## Phase 8 — PDF and CSV reports

**Goal:** Export audit results for documentation. All roles can export.

**Tasks**
1. `ReportService` with:
   - `byte[] BuildComputerAuditPdf(int computerAuditId)`
   - `byte[] BuildAuditRunPdf(int auditRunId)`
   - `byte[] BuildAuditRunCsv(int auditRunId)`
2. **PDF (QuestPDF)**, A4 portrait, brand colors:
   - Header on every page: logo + "SecureCheck — Endpoint Security Audit Report", generated date/time, generated by.
   - Run report: summary (date, computers audited, average score, count per risk level), a table of computers (name, location, score, risk, failed count, status), then one section per computer with its failed checks (check, risk, actual, expected, how to fix).
   - Computer report: same as one computer section, plus passed checks list and comparison with previous audit.
   - Footer: "Page X of Y".
3. **CSV (CsvHelper)**: one row per check result with columns: RunId, ComputerName, HostName, Location, AuditedAt, ComputerScore, ComputerOverallRisk, CheckCode, CheckName, Category, RiskLevel, Status, ActualValue, ExpectedValue. Unreachable computers get one row with Status = Unreachable and the error message.
4. **Reports page** (`Pages/Reports`): pick an audit run (latest first) → buttons "Download PDF" and "Download CSV". Also add "Export PDF" buttons on the Run Details and Computer Result pages.
5. File names: `SecureCheck_Run{id}_{yyyyMMdd}.pdf`, `SecureCheck_{ComputerName}_{yyyyMMdd}.pdf`, `SecureCheck_Run{id}_{yyyyMMdd}.csv`.
6. ActivityLog every export.

**Done when**
- [ ] PDFs open correctly, show the logo, and long tables continue onto the next page cleanly.
- [ ] CSV opens in Excel with correct columns.
- [ ] A Viewer can download reports.
